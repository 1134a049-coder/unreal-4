# Unreal Engine 4.27 Interactive Certification & Quiz Platform
虛幻引擎 4.27 24小時官方教材全真互動測驗與刷題系統（Hour 01 ~ 07 + 01_to_06_Test + 07_to_13_Texs）

本專案將官方教材《Teach Yourself Unreal Engine 4 Game Development in 24 Hours》前 7 個章節（Hour 01 ~ 07，共 70 題）以及兩份官方階段綜合測驗（`01_to_06_Test` 30 題、`07_to_13_Texs` 30 題），共計 130 道全真考題完整現代化重構，採用頂級教育科技 UI（參考多益線上測驗系統 TOEIC Pro 介面架構），完全獨立集中於單一資料夾，支援 GitHub 快速上傳與 GitHub Pages 零配置一鍵部署。

## 🌟 核心特色功能

1. **考題以英文原文為主，繁體中文翻譯為輔**：
   - 預設提供 **「英中雙語對照模式」**（英文考題在上、高雅淡藍色中文翻譯卡在下）。
   - 頂部支援一鍵切換：`English 原文`（擬真官方認證環境）、`英中雙語對照`、`精闢詳細版翻譯`（專有名詞隨文註解）、`繁體中文`。
2. **100% 逐字核對官方考題與標準解答**：
   - 7 個章節 + 2 份階段綜合測驗（`01_to_06_Test`、`07_to_13_Texs`），共 130 道題目。
   - 包含是非題（True / False）與四選一單選題，考題字元、標點與正確答案完全與原始教材考卷 100% 契合。
3. **專為 Unreal Engine 4.27 版本定製之深入內容解釋**：
   - 包含細節面板（Details）、專案結構（.ini/Saved）、左手坐標系、靜態網格碰撞（Simple vs Complex）、Lightmass 光照烘焙、PBR 基於物理著色（Albedo/Roughness/Metallic）、Sound Cue 音訊系統、地貌雕刻、大氣霧與後製處理、Cascade 粒子、Sequencer 電影序列器與物理破碎模擬。
   - 逐題詳解「正確答案核心邏輯」與「干擾選項功能對比」。
4. **完整測驗模式與星號標註篩選**：
   - **刷題練習模式**：即時回饋正誤、可自由開啟/關閉答案顯示與專業解釋、支援「★ 星號標註篩選」（一鍵篩選當前章節已標註星號題目）。
   - **全真章節模考**：章節 30 分鐘 / 綜合測驗 60 分鐘官方倒數計時器（倒數 5 分鐘緊急變色警示），每題 2 分（10 題滿分 20 分 / 30 題滿分 60 分），考後生成成績單與答對率結算。
   - **智慧錯題本、星號標註總覽與全站作答本地端儲存 (LocalStorage)**：頂部導覽列支援切換「錯題本」與「星號標註」模式，所有章節的作答選項、正誤狀態、星號標註（★）即時自動持久化儲存，**網頁刷新、重開分頁或關閉瀏覽器絕不丟失任何進度**。
5. **右側題目卡導覽盤與鍵盤快捷鍵**：
   - 1~10 題號盤視覺化標示未答、已答、標記（★）、答對（綠色）、答錯（紅色）。
   - 支援鍵盤快速鍵：`← / →` 題號切換、`1/2/3/4` 或 `A/B/C/D` 快速選擇答案。

## 🚀 部署至 GitHub Pages 指南

1. 將本 `ue_quiz_website` 資料夾內的所有檔案上傳或推送至您的 GitHub 儲存庫（Repository）的 `main` 分支。
2. 進入該 GitHub 儲存庫的 **Settings** -> **Pages**。
3. 在 **Build and deployment** -> **Branch** 選擇 `main` 分支與 `/ (root)` 資料夾，點擊 **Save**。
4. 等待約 1 分鐘，即可獲得公開線上的測驗系統網址（如 `https://<username>.github.io/<repo>/`）。
